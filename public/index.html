Worker 在线构建器

在左侧「设置」中配置 OpenAI 兼容大模型（Base URL / Key / 模型，例如 DeepSeek） 与 Cloudflare 凭据，然后新建项目，用对话描述你想要的 Worker， 系统会自动生成代码并部署到 Cloudflare Workers，直接给你可访问的地址。

1

配置大模型与 Cloudflare

一次配置，登录态持久保存，之后无需重复登录。

2

新建项目并对话

描述需求，Agent 生成完整 Worker 代码，可多轮迭代修改。

3

自动部署拿地址

一键发布到 workers.dev，立即在浏览器访问效果。
